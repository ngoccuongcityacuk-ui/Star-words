📘 Hướng dẫn cho giáo viên

1. Dùng ngay: Mở file này bằng trình duyệt (Chrome, Safari, Edge…) trên máy tính, điện thoại hay máy tính bảng đều được. Học sinh gõ tên, chọn unit và bắt đầu chơi.

2. Giao bài về nhà: Gửi file star-words.html cho phụ huynh, hoặc đưa lên một trang web miễn phí (Netlify Drop, GitHub Pages, Google Sites…) rồi gửi đường link cho cả lớp.

3. Sửa / thêm từ vựng: Mở file bằng Notepad (Windows) hoặc TextEdit (Mac). Tìm phần const UNITS ở đầu thẻ <script>. Mỗi từ có dạng { en:"apple", emoji:"🍎" }. Copy một dòng, đổi chữ và emoji là thêm được từ mới.

3b. Dùng ảnh thật thay emoji: Tìm dòng const IMAGE_MODE ở đầu thẻ <script>. Đổi thành "folder" rồi bỏ ảnh vào thư mục images đặt cạnh file (đặt tên theo từ: images/apple.jpg...). Hoặc đổi thành "auto" để tự lấy ảnh trên mạng (nhanh nhưng ảnh ngẫu nhiên). Thiếu ảnh thì app tự dùng lại emoji.

4. Theo dõi kết quả: Cuối mỗi trò chơi có màn hình "giấy khen" ghi tên và điểm — học sinh chụp màn hình gửi cho cô là được. Bản này chưa tự lưu điểm lên máy chủ.
